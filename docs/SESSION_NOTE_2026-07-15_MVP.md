# Session Note: 一世帯限定MVPの安全対応

日付: 2026-07-15

## 結論

人の操作を必要としない範囲で、一世帯限定MVPを安全に試すためのコード変更、テスト、本番反映を完了した。

本番Web: https://dhr30db6tf09e.cloudfront.net

- Webは共有アクセスコード必須になった
- 検索エンジンには公開しない設定にした
- Alexa Lambdaの危険になり得る文言と特定薬名の固定を解消した
- WebとAlexaは引き続き `default-user` を共有するため、一般公開・複数世帯利用は不可

アクセスコードとセッション署名用シークレットはSST Secretに保存し、リポジトリには保存していない。アクセスコードはオーナーへ別途引き渡す。

## 実装した内容

### Web

- 共有アクセスコードによる一世帯用ゲート
- HMAC署名済み、HTTP-only、SameSite Strict、Secure Cookie
- 未認証ページを `/login` へ転送し、未認証APIを401にする
- 各記録APIでも認証を再確認する多層防御
- ログイン・ログアウト、同一オリジン確認、失敗時の応答遅延
- 日付・月・時刻・服薬タイミング・記録ID・メモ長の入力検証
- 存在しない記録を更新で新規作成しない条件付き更新
- APIエラーを画面に伝え、401時はログインへ戻す
- 日本語のプライバシーポリシーと利用条件（限定ベータ向け案）
- 全ページの `noindex` と、全クロールを拒否する `robots.txt`
- 外部フォント取得をなくし、再現可能な本番ビルドに変更

### Alexa

- 「レボドパ」のハードコードを除去
- `MEDICATION_NAME` と `REMINDER_SCHEDULE_JSON` で薬名・時刻を設定可能にした
- 未設定時は特定薬名を言わない一般的なリマインダーにした
- 夜9時の応答から、看護師への連絡を控えさせる可能性がある表現を除去
- リマインダー取得・削除失敗時の例外処理
- ハンドラーをテスト可能な構造に変更
- DynamoDBリージョンの既定値を実環境の `us-east-1` に修正

- CIにAlexa/Webのテスト実行を追加
