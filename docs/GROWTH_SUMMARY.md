## 3行でいうと

1. **大企業営業は今やらない**。意思決定まで12〜18ヶ月かかり、その間に個人ユーザーを100人取れる
2. **最初の10人は医療関係者の個人紹介だけで取る**。アプリストアもSNSも今は不要
3. **10人→30人は Alexa スキルストア + note + 小規模施設への直営業の3本柱**

---

## どのチャネルを選ぶか

### 医療関係者の個人紹介（0→10人：これだけでいい）

- 訪問看護師・ケアマネジャーの知り合いに連絡して患者家族を1〜2人紹介してもらう
- App Store に出しても★が0件では誰もダウンロードしない
- SNS のフォロワーが増えてもコンバージョンは 1% 以下
- **医療従事者からの紹介は信頼付きで来るので継続率が全然違う**

### 10→30人：3チャネルを並行で動かす

| チャネル | 何をするか | いつ始めるか |
|---------|-----------|------------|
| **Alexa スキルストア** | スキル説明文を「服薬管理」「飲み忘れ防止」でSEO最適化。10人にレビューを頼む | 7人達成後すぐ申請 |
| **note 記事** | 「Alexaで親の服薬を管理した話」などの介護×テクノロジーストーリー。月1本 | 10人達成後 |
| **小規模グループホーム直営業** | 地元5〜10施設に電話か訪問。「3ヶ月無料トライアル」で提案 | 10人達成後 |

## 大企業への営業はどう考えるか

### やってはいけない理由（今のフェーズ）

- 1社の契約を取るのに 6〜18ヶ月かかる
- セキュリティ審査・ISMS・SLA 保証が必要
- マルチユーザー認証がまだない（現状 USER_ID 固定）
- 担当者が変わるとゼロからやり直し

### 代わりに狙うべき：小規模グループホーム

```
定員 5〜29人 の施設 → 意思決定者が現場にいる → 1〜2週間で結論が出る
```

大企業と違い「使ってみてよかったら続ける」で動いてくれる。1施設入れると口コミが広がる。

### 大企業を検討するタイミング

以下が全て揃ったら:

- MAU 100人以上
- Cognito 認証 + 監査ログ実装済み
- セキュリティ診断完了
- 個人情報保護方針・利用規約の法的整備済み

## AWS インフラコスト（Vercel を使わない理由）

| 規模 | 月額 | 内訳 |
|------|------|------|
| 0→30人 | **¥0〜¥300** | Amplify / DynamoDB / Lambda すべて無料枠内 |
| 30→100人 | **¥750〜¥7,500** | Amplify 従量課金 + Cognito |
| 100人〜 | 要見積 | Amplify Pro / RDS / SES |

Vercel Pro（¥3,000/月）より安く、しかも DynamoDB / Lambda / Cognito と同じ AWS アカウントで IAM ロールが使えるのでアクセスキーの管理が不要になる。

## 失敗パターン（避けること）

| NG | 理由 |
|----|------|
| 広告を先に打つ | 口コミゼロの状態で広告を出しても費用対効果が最悪 |
| 大企業を先に狙う | 12ヶ月かかる、その間に個人100人取れた |
| SNSに時間をかけすぎる | フォロワー増≠ユーザー増 |
| 機能追加に集中しすぎる | 使われていない機能を作っても意味がない |
| 「30人いるが誰も毎日使っていない」 | 数より継続率を優先する |
